# IT Conference App

Учебный React-проект: лендинг IT-конференции **NextConf** с секцией спикеров и FAQ.

## Стек

- **React 18**
- **Vite 5**
- **CSS** (без препроцессоров и CSS-in-JS)
- **ESLint** (по желанию)

## Требования

- Node.js **18+**
- npm **9+** (или pnpm / yarn)
